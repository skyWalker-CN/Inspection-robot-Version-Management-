# 已知人脸目录

本目录用于存放已知人员的照片，用于人脸识别功能。

## 目录结构
```
known_faces/
├── 张三.jpg          # 员工张三的照片
├── 李四.jpg          # 员工李四的照片
├── 王五.jpg          # 员工王五的照片
├── 访客_赵六.jpg     # 访客赵六的照片
└── README.md         # 本说明文件
```

## 照片要求

### 格式要求
- **支持格式**: JPG, JPEG, PNG
- **推荐格式**: JPG
- **文件大小**: 建议小于 5MB

### 质量要求
- **分辨率**: 建议至少 200x200 像素
- **清晰度**: 人脸清晰，无严重模糊
- **角度**: 正面照片，人脸角度不超过 30 度
- **光照**: 光线充足，避免严重阴影
- **表情**: 自然表情，避免夸张表情

### 命名规范
- **员工照片**: 直接使用姓名，如 `张三.jpg`
- **访客照片**: 使用 `访客_姓名` 格式，如 `访客_赵六.jpg`
- **文件名**: 只能包含中文、英文、数字和下划线
- **扩展名**: 小写，如 `.jpg`, `.png`

## 使用说明

1. **添加新人员**:
   - 将照片放入此目录
   - 按照命名规范命名文件
   - 重启异常检测节点

2. **删除人员**:
   - 删除对应的照片文件
   - 删除对应的特征文件（.npy 文件）
   - 重启异常检测节点

3. **更新照片**:
   - 替换原有照片文件
   - 删除对应的特征文件（.npy 文件）
   - 重启异常检测节点

## 特征文件

系统会自动为每张照片生成特征文件（.npy 格式），用于快速人脸识别：
- **位置**: 与照片文件在同一目录
- **命名**: 与照片文件同名，扩展名为 .npy
- **作用**: 存储人脸特征向量，提高识别速度

## 注意事项

1. **隐私保护**: 确保照片使用符合隐私保护法规
2. **定期更新**: 建议定期更新员工照片，保持识别准确性
3. **备份**: 定期备份照片文件
4. **权限**: 确保目录具有适当的读写权限
